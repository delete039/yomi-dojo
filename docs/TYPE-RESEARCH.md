# `/type`「看汉字打读音」参考站研究

研究日期：2026-11-08  
参考地址：`https://jp-master.com/type`  
取证方式：ego-lite 实际操作、DOM/CSS/布局读取、网络请求与响应记录、截图对照  
范围：只研究「看汉字打读音」以及开始练习所必需的词包选择、导入、设置与结算

> 本文记录的是已观察、已操作验证的行为。没有把截图推测写成事实；无法验证的边界单独列出。

## 1. 结论摘要

参考站的核心不是普通表单输入，而是一个逐键判定的打字状态机：

1. 题目显示汉字、释义、逐音读音槽和组内进度。
2. 键盘按键由一个视觉隐藏的输入框接收；页面按字符立即判断正确或错误。
3. 正确音会让当前槽位点亮，并播放 `key-pop`、扩散圆环与机械键音。
4. 错误音会让当前槽位变红、读音行抖动、累计错误并播放错误音。
5. 一个词全部正确后立即推进到下一词，上一词的结果行短暂出现在进度条下方。
6. 一组完成后进入统计页，列出用时、速度、正确率、连击与薄弱词。
7. 词包面板、设置面板和导入面板都以内联折叠区出现，不使用全屏路由。

参考站以固定 20 词为一组。新项目不照搬这个业务限制：保留同样的页面节奏与视觉，但每组词数由用户选择，选题仍来自整包动态队列。

## 3. 页面结构

### 3.1 桌面

参考站桌面视口为 `1041×917`，DPR 1.5：

- 顶部全局导航高 `63px`，背景 `#1c1c1c`，底部 1px 边线。
- 打字内容最大宽度 `720px`，水平居中。
- 打字页头部外框高 `63px`（内部控件高 `45px`）：返回、练习模式胶囊、设置按钮。
- 下一行是“我的词”折叠触发器。
- 主体 section 顶部距全局导航约 `130px`。
- 汉字标题视觉字号 `67.5px`、行高 `67.5px`、字重 600。
- 释义 `15.75px`、行高 `22.5px`。
- 读音槽每格宽约 `59.4px`，行高约 `61.5px`，格子水平间距 `4.5px`。
- “按住看读音”按钮高 `40.5px`、圆角 `9px`。
- 快捷键说明 `13.5px`，颜色 `#7a766f`。

### 3.2 移动

移动视口为 `390×844`，根字号 `15px`：

- 页面没有桌面全局导航；打字页头部高 `52.5px`。
- 内容左右内边距 `15px`，练习 section 宽 `360px`。
- 汉字标题 `45px`，释义 `13.125px`。
- 提示按钮高约 `33.75px`。
- 底部主导航固定在视口底部，5 项，每项约 `78px × 51px`，文字 `10px`。
- 词包 panel 的组格从桌面 10 列变为 5 列。

## 5. 练习页状态

### 5.1 初始态

- 组内进度：`1 / 20`。
- 速度：`0 假名/分`。
- 正确率：`100%`。
- 所有读音槽为低对比度占位。
- 当前字符底部有 accent 下划线，并以 `caret` 动画闪烁。
- 隐藏输入框自动获得焦点。
- 进度条填充宽度使用「已保存答案数 / 本组总词数」，第一题时为 0%，而不是当前题号。

### 5.2 罗马字待定态

- 输入未形成完整音节时，例如目标 `か` 输入 `k`，不会判错。
- 当前槽下方显示 pending，例如 `k`、`ky`。
- 已确认读音继续保留亮色。

### 5.3 正确音

- 当前读音槽变亮。
- 触发 `key-pop`。
- 当前槽附近出现扩散 ring。
- 光标推进。
- 开启按键音时播放机械键音。

### 5.4 错误音

- 当前槽和下划线变红。
- 整个读音槽容器触发 `nope` 抖动。
- 错误数和输入总数增加，正确率下降。
- pending 清空。
- 开启按键音时播放错误音，并调用 `navigator.vibrate(30)`（设备支持时）。
- 已确认位置不回退。

### 5.5 提示

- 按住空格或按住“按住看读音”按钮时显示当前读音。
- 松开后隐藏。
- 使用提示会标记本词“看了读音”。
- 设置“提示：不显示”时，未输入槽位显示透明的 `・`，但下划线仍在；按住提示仍可临时显示。
- 键盘提示使用 `Space` / `Tab`，并忽略重复 keydown。

### 5.6 跳过

- `Escape` 跳过当前词。
- 错误累计到 3 次后，页面出现“跳过”按钮。
- 跳过词会进入结算的薄弱词列表。
- 跳过按钮使用 `skip-forward` 图标，错误达到 3 次前不渲染。

### 5.7 上一词结果行

正确答案完成后、下一题开始期间，进度条下方出现：

`✓ 上一词汉字  读音  释义`

切换题目时使用短促的入场动画，而不是长时间停留的答题反馈页。

### 5.8 单词完成覆盖层

正确完成一个词后，参考站不会显示整屏反馈页，而是在读音行位置叠加上一层已完成读音：

- 旧读音字符整体变为 `success`，以 `fly-out .42s cubic-bezier(.3,.7,.3,1) both` 上浮淡出；
- 同一覆盖层中心生成 **12 个** `spark`，每个粒子使用精确的 `--dx` / `--dy`：

```text
angle = index / 12 * 2π
distance = 70 + (index % 3) * 22
dx = cos(angle) * distance * 1.6
dy = sin(angle) * distance
```

- 覆盖层下方的新题读音行立即存在，并以 `rise-in .3s cubic-bezier(.2,.9,.3,1) both .2s` 入场；
- 新题汉字和释义也使用 `rise-in`，所以输入可以在旧读音飞出时继续。

## 6. 进度与结算

进度条上方：

- 桌面：左为 `当前 / 总数`，右为 `速度 假名/分 · 正确率`。
- 移动或连续正确时：中间可显示 `连击 N`。

补充实测（2026-11-08，已登录会话）：

- 连击 `N` 在连续正确键数达到 `5` 时出现；`5` 以下不渲染。
- 只有跨过 10 的整数倍时才触发一次 bump 动画；`30` 起文字变为 accent 色。
- 按住读音提示不会重置连击；`Escape` 跳过也不会重置连击。
- 输入错误键会立即重置连击，下一键从 1 重新累计。
- 速度从本组首个有效按键开始计时，且运行中只有经过 `2 秒` 后才显示非零值。

完成一组后：

- 4 个统计卡：用时、假名/分、正确率、最高连击。
- 标题格式：`打错或看了读音的 N 个`。
- 无薄弱词时标题为：`N 个全部一次打对`。
- 薄弱词排序：跳过优先，然后按错误次数降序。
- 逐行展示汉字、读音、释义、结果标签（`跳过` / `看了` / `错 N`）。
- 状态标签颜色为 `danger-fg`；列表行间隔 50ms stagger。
- 操作为 `下一组`（主按钮 + chevron）、`第 N 组再打一遍`（次按钮 + rotate-ccw）和 `只练这 N 个`（描边按钮）；没有下一组时，重打按钮成为主按钮并显示 `再来一组`。

参考站结算页仍保留顶部全局导航、打字页头部、词包触发器和设置面板，因此结算不是独立全屏页面，而是同一个 `/type` 路由内的完成状态。

## 7. 词包面板

触发器固定文案为「我的词」，带展开箭头；当前选中的词包在面板 chip 中体现。

面板内容：

- 词包 chips：`我的词`、`N2 高频词`、`N1 高频词`、`+ 导入词包`。
- 当前词包信息：`883 个词 · 45 组 · 打完 0 组`。
- 组格：桌面 10 列、移动 5 列，最大高度约 `224px`，可滚动。
- 已完成组格显示成绩摘要；当前组用 accent 填充。
- 自定义词包有删除入口。

参考站 API 的 N1/N2 为固定 20 词分组。新项目决策：

- 仍以“词包 → 组”呈现；
- 组数由当前每组词数和整包可练词数推导；
- 选题仍为整包动态队列；
- 每个词包保留自己的未完成组，切换词包不会覆盖。

## 8. 设置面板

三行分段控件：

| 行 | 选项 | 参考站默认 |
| --- | --- | --- |
| 提示 | 显示读音 / 不显示 | 显示读音 |
| 按键音 | 开 / 关 | 开 |
| 发音 | 不读 / 打完读出来 | 不读 |

设置面板由齿轮按钮切换；再次点击关闭。设置写入本地偏好。

新项目还会把“答对后自动继续”与本组词数纳入设置，但会保持参考站三行主面板的紧凑结构，避免改动核心视觉。

## 9. 导入流程

词包面板里的“+ 导入词包”展开内联面板：

1. 输入词包名称（可空，保存时使用默认名）。
2. 文本域输入一行一个词。
3. 支持：
   - `侮る`
   - `荷\tに\t负担`
   - `拍子, ひょうし, 节拍`
4. 下一步后，服务端词典为缺读音行自动补读音。
5. 无汉字行被跳过。
6. 预览行可编辑假名；自动标注读音用 accent 边线提示。
7. 保存后创建词包并切换。

实测预览响应包含 `rows`、`skipped`、`skipped_count`。参考站的自动读音依赖其私有服务端，新项目改用本地离线词典补全。

## 11. 输入匹配规则

参考实现不是简单的 `wanakana.toKana` 后全串比较，而是从当前位置动态生成可接受拼写：

- `し`: `shi` / `si` / `ci`
- `じ`: `ji` / `zi`
- `ち`: `chi` / `ti`
- `つ`: `tsu` / `tu`
- `ふ`: `fu` / `hu`
- `を`: `wo` / `o`
- 小写元音：`xa/la` 等
- 促音 `っ`：复制下一个辅音，也接受 `xtu` 等
- 拨音 `ん`：`n` / `nn` / `n'` / `xn`，并根据后接元音决定裸 `n` 是否可立即提交
- 拗音：`ky + a/u/o`、`sh`、`ch`、`j` 等
- 外来音组合：`she`、`che`、`fa`、`thi`、`twu`、`va` 等
- 未完成拼写属于 pending，不判错
- 错误按键不移动已确认位置

新项目将提取为独立、可测试的 `RomajiMatcher`，不依赖参考站源码。

## 12. 音效和发音

参考站使用 Web Audio 合成：

- 正确键：50ms 随机噪声，带通 2600–3500Hz、Q 1.2，叠加 190→70Hz 正弦短音。
- 错误：180Hz/140Hz 两段三角波，间隔约 70ms。
- 完成成功：1046.5Hz 与 1568Hz 正弦，第二音延迟 60ms，衰减约 450ms。

新项目会独立实现同量级的合成音。参考站发音通过私有 `/api/tts`；新项目使用浏览器 `speechSynthesis`，交互行为等价，但音色无法保证一致。

已验证 keyframes：

| 名称 | 参数 |
| --- | --- |
| `caret` | `1s ease-in-out infinite`，中点透明度 `.2` |
| `rise-in` | `.3s cubic-bezier(.2,.9,.3,1)`，Y +8px → 0 |
